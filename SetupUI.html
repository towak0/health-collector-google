3

配布用の URL

被験者が開くページのアドレスです。Apps Script の「デプロイ」で発行した /exec で終わる URL を入れてください。

この URL は被験者に配るリンクの土台になります。あとで「新しいデプロイ」を作ると URL が変わり、配布済みのリンクが全部無効になります。更新するときは必ず 「デプロイを管理」から既存のデプロイの新しいバージョンとして行ってください。
4

試験の設定

Google Cloud で発行したクライアント情報と、被験者IDの付け方を決めます。

内部で使う名前。英数字と _ のみ。
Experiment_A_001 のように採番されます。
保存先は Script Properties のみ。シートにも画面にも残りません。
配布後にこの2つは変えられません。 試験の識別子はトークンの保存キー、接頭辞は被験者IDそのもので、 シート・Drive のパス・配布済みリンクに埋め込まれます。決め直すなら今のうちに。
